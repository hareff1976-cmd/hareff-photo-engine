# HAREFF Photo Engine 1.0 RC

Premium Black · бесплатная демонстрационная сборка проекта для тестирования.

Откройте `index.html` для редактора, `studio.html` — для описания проекта.

## GitHub Pages

1. Загрузите все файлы из этого архива в корень репозитория `hareff-photo-engine` (ветка `main`). Не загружайте сам ZIP.
2. Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save.
3. После успешного развёртывания откройте опубликованный HTTPS-адрес.
4. Chrome Android → меню ⋮ → Установить приложение / Добавить на главный экран.
5. В редакторе откройте ПРОЕКТЫ / PWA, проверьте статус офлайн-кэша. Проверьте повторный запуск из иконки в авиарежиме, загрузку и экспорт фотографии, сохранение и восстановление проекта.

Все файлы PWA лежат в корне, относительные ссылки рассчитаны на подпапку репозитория.

## Ограничения

RAW: ограниченная поддержка несжатого Bayer DNG; главный редактор 8 бит. Лицензирование демонстрационное, продаж и оплаты нет. Установка и офлайн-режим должны быть проверены на реальном HTTPS-сайте. Локальные проекты не переносятся между браузерами или доменами; очистка данных сайта удалит их.

Публичный репозиторий раскрывает исходный код; опубликованный HTML/JS доступен посетителям. Публикация не означает предоставления лицензии на повторное распространение. Не загружайте личные фотографии, ключи, токены или платёжные данные.
